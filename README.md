# Hogarflow

SaaS multi-tenant para gestionar viviendas en alquiler, ingresos, gastos y documentacion familiar.

## Estructura

- `backend`: API Node.js + Express + TypeScript conectada a Supabase PostgreSQL.
- `frontend`: Next.js App Router + Tailwind CSS.

```bash
cd backend
npm install
npm run dev
```

```bash
cd frontend
npm install
npm run dev
```
